# Sistema de Ferretería (React + Vite)

Sistema para llevar el control de una ferretería: productos, clientes, ventas e historial.
Los datos se guardan en el navegador (localStorage).

## Cómo correrlo
1. `npm install`
2. `npm run dev`
3. Abrir la dirección que sale en la terminal (normalmente http://localhost:5173)

## Funcionalidad
- Productos: agregar, editar y eliminar. Stock menor a 5 se marca en rojo.
- Clientes: agregar y listar.
- Nueva venta: carrito, total, validación de stock y descuento automático.
- Historial: ventas con su detalle.
